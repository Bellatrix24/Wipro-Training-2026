# Module 04: Asp.Net Core (Razor Pages & MVC)

## Daily Summary
Today's focus was learning the fundamental architecture of modern web applications. A web framework like ASP.NET Core acts as a bridge between the front-end browser and our secure C# backend. 

Whenever a user visits our website, the front-end browser sends a web request. Our secure C# backend catches this request, runs our logic (like talking to a database or checking credentials), and then sends back an HTML page or a message. This keeps our sensitive business logic and data securely protected on the server side.
